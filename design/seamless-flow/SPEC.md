## 1. 핵심 흐름 설계 — "기본 → 인물 → 구도 → 연출 → 생성" 단일 레일

### 1.1 핵심 완주 체인 (하단 `이전` / `다음` 100% 연결)
하단 우측 `다음` 버튼만 순서대로 눌러도 처음부터 생성 화면까지 끊김 없이 완주되도록 체인을 고정한다.

`[01 기본]` **그림체(`style`)** → **등장 인원(`count`)**
→ `[02 인물]` **캐릭터(`char`)** → **복장(`cloth`)** *(선택 진입: 외형·동작·표정)*
→ `[03 구도]` **장면 구성(`pose`)** *(선택 진입: 카메라)*
→ `[04 연출]` **장소(`env`)** → **조명(`light`)** *(선택 진입: 강도·분위기)*
→ **`이미지 생성 (스튜디오)`**

- **하단 좌측 `이전` 버튼**:
  - 체인 첫 단계(`그림체`)에서만 비활성(`disabled`), 그 외 모든 단계에서 **활성 대비 스타일(밝은 텍스트 `#E0DFE8` + 테두리 `#454550`, 비활성 회색과 명확히 구분)** 적용.
  - 목적지 라벨 통일: `이전 · 그림체`, `이전 · 인원`, `이전 · 캐릭터`, `이전 · 복장`, `이전 · 장면`, `이전 · 장소`.
- **하단 우측 `다음` 버튼**:
  - 모든 단계에서 목적지 라벨 통일: `다음 · 인원`, `다음 · 캐릭터`, `다음 · 복장`, `다음 · 장면`, `다음 · 장소`, `다음 · 조명`.
  - 마지막 핵심 단계(`조명`)의 우측 버튼은 **`이미지 생성 →`**으로 스튜디오 탭에 즉시 연결.
  - 기존 `1-3 캐릭터`에서 `다음` 목적지가 빠지던 불일치 해소.

### 1.2 상단 4대분류 그룹 스위처 (지금 어디인지 항상 표시)
- 기존 세부 화면 상단의 평면 7개 칩(`그림체 · 인원 · 캐릭터 · 복장 · 장면 · 장소 · 조명`)에 **4대분류 구분 표시**를 넣거나 **2단 경량 바(상단: `01 기본`·`02 인물`·`03 구도`·`04 연출` 진행 상태 / 하단: 해당 대분류의 항목 칩)**로 정리한다.
- 어떤 세부 화면에 있든 현재 소속 대분류(`01~04`)가 명확히 강조되며, 대분류 클릭 시 해당 대분류의 첫 핵심 항목(또는 허브)으로 즉시 이동한다(`undoStack` 비오염).
- `1-3. 캐릭터`처럼 `01 기본` 번호(`1-`)를 달고 실제 뒤로가기 시 `02 인물` 허브로 복귀하던 **번호·소속 불일치**를 `01~04` 체계에 맞춰 통일한다.

## 2. 화면별 사용감 · 시각 마감 패치 (라이브 `v3.3.12` 실측 4건)

### 2.1 `그림체` 카드 높이 컴팩트화 + `...` 버튼 라벨 명시
- 현재 `블루아카` 카드의 세로 높이가 지나치게 커서 진입 직후 화풍 이름(`✓ 블루아카`)이 하단 바 아래로 잘리는 문제를 수정한다.
- 썸네일 이미지가 없는 기본 카드의 세로 높이를 컴팩트하게 제한(`min-height: 96px~128px` 수준)해 **진입 즉시 화풍 제목·선택 체크·설명이 스크롤 없이 한눈에 보이게** 한다.
- 하단 전체 폭 `...` 버튼에 명확한 텍스트 라벨(예: `화풍 관리 · 연구소 열기`)을 부여한다.

### 2.2 1개짜리 가짜 서브탭 숨김 & 중복 상단 여백 압축
- `.d3-progress` 내부 버튼이 **1개 이하**인 경우(`화풍 선택`, `인원 선택` 등) 해당 밑줄 바 자체를 `display: none`으로 숨긴다.
- 세부 화면 헤더 아래 불필요한 상단 공백을 줄여, 진입 즉시 선택 카드(`인원 6종`, `캐릭터`, `복장 6종`)가 시선 정중앙에 바로 들어오게 한다.

### 2.3 좌측 상단 이중 `<` 뒤로가기 오터치 방지
- 세부 화면이 열렸을 때 최상단 `< 빌더`(홈으로 이탈)와 바로 아래 `< {항목명}`(목록/허브 복귀)이 똑같은 `<` 기호로 세로 중복되는 혼선을 해소한다.
- 최상단 버튼은 `홈` 아이콘/라벨로 구분하거나 세부 화면 중에는 허브 복귀 `< 목록` 버튼 1개만 강조해 실수로 홈으로 튕기는 오터치를 막는다.

### 2.4 `01 기본` 허브 화면 균형 정리
- `기본` 허브에 `그림체`·`등장 인원` 2개 카드만 놓여 하단 70%가 비어 보이는 구간에, 현재 선택 요약 및 **`바로 순서대로 시작 (그림체 → 인물 → 구도 → 연출)`** 또는 최근/자주 쓰는 빠른 진입 동선을 깔끔하게 배치해 허브의 허전함을 줄인다.
