# ATELIER 디자인 결정 기록

- R0 One Touch: 일반 옵션은 한 번 누르면 즉시 적용. 해제 허용 옵션은 다시 누르면 해제. 필수 선택/복구 불가능 작업의 기존 안전 계약 유지.
- R1 Vertical Quick Rail: 커버 및 펼침 세로 레일. 폭 56px, 아이콘과 한글 라벨. 기본 커버 오른쪽/펼침 왼쪽, 화면별 위치 설정 독립 유지. 활성 영역 및 실제 선택 개수 표시. 이동 시 상태/스크롤 유지, Undo 오염 금지.
- R2 Adaptive Cards: 의미에 따라 시각 카드, 아이콘 카드, 텍스트 칩 혼합. 기존 분류/ID/선택 규칙 보존. 접힌 섹션에서 현재 선택 확인.
- R3 Generation Dock: 복사 중심 메인 조작부를 생성 중심으로 전환. 기존 복사 기능/슬롯 계약 보존. 생성은 명시 클릭으로만 실행. 생성 설정과 현재 선택 요약 표시. 커버 접힌 요약에도 주요 선택과 나머지 개수 표시, 펼침 독립 스크롤 인스펙터.
- R4 Canvas: 작품 감상/정보 UI 제안 중 기존 생성 화면 변경과 충돌하는 부분은 보류. 생성 화면·로딩 디자인 변경 금지. 기존 결과 및 생성 당시 정보 보존.
- R5 Motion: 짧고 절제된 시각 피드백, 기존 브리지 범위 안의 햅틱, reduced-motion 존중. 새 캐릭터 로딩 폐기.
- 기존 홈/브랜드 유지. 시안 메뉴·샘플 데이터는 제품 데이터 삭제 지시가 아니다.
- 기존 토큰 우선: #111116 / #20202B / #A89BFF / #C4BAFF / #171126 / #E0DFE8 / #9693A3 / #2B2B36 / #454550.
- 터치 44px+, 일반 글자 13px+. 불필요한 확인·팝업 최소화. 제품 상태가 단일 진실 원천.
- 웹 전용 v3.3.0 계획. APK 1.1 유지.

최종 외형 기준은 DESIGN.html과 이 문서의 결정이다. 시연 전용 정보와 인터랙션은 제품 기능이나 실행 증거가 아니다. 세부 배치/설정 저장 계약은 실물 코드와 대조해 확정한다.

## R1b 최신 사용자 변경 승인 (2026-11-28)

- 의상은 인물에 통합. 기존 복장 변경 카드, 선택값, 상세 편집기 보존.
- 배경은 연출에 통합. 기존 장소 카드, 조명, 분위기 및 고급 설정 보존.
- 레일 순서: 화풍 → 인물 → 구도 → 연출 → 스튜디오. 기존 최종 확인 진입도 유지.
- 스튜디오는 기존 생성 화면으로 이동하는 진입점이며 생성 실행 버튼이 아니다. 선택 개수 배지 없음. 기존 생성 화면과 로딩 유지.
- 이전 DESIGN.html의 6개 편집 카테고리 표시는 역사적 승인 시안이며, 위 사용자 변경 사항이 해당 부분에 우선한다. 원본 파일은 보존한다.

## R1b 추가 사용자 결정
- 퀵레일에서 최종 확인 항목 제거. 최종 레일은 화풍·인물·구도·연출·스튜디오 5개만 노출.
- 기존 step-4 및 출력/UC/복사 계약은 보존하고, 더보기 → 완성 프롬프트 보기 경로를 유지. 기존 하단 단계 이동은 R3 Dock 연결 전까지 유지.
- 이전 최종 확인 레일 유지 결정은 본 변경으로 대체.
