# ATELIER 제품 연결 요구사항 (구현 전 기록)

기준 main 및 최신 규약 확인 후 DESIGN.html을 기존 제품 UI에 연결한다. 이 문서는 실물 코드 대조를 완료한 상세 구현 명세나 제품 후보가 아니다.

1. 기존 단일 HTML, DOM ID/CSS 변수, 기존 상태와 이벤트 계약 보존. 화면 이동은 표시 전용 상태로 관리하고 동적 필터의 논리 숨김과 구분.
2. 레일/카드/선택 요약은 기존 실제 상태를 읽고 기존 변경 경로 호출. 중복 선택 상태 금지. 실제 상태 변경만 Undo 1회, 최대 15단계. 조회/탐색/동일값은 Undo 없음. 자동 해제도 즉시 표시.
3. 생성 Dock은 기존 명시적 생성 경로와 busy/취소/429 정책을 연결. 실제 API 호출 없이 테스트. 기존 생성 화면·대기 표현 보존. 복사 기능/슬롯 출력 삭제 금지.
4. 커버 오른쪽/펼침 왼쪽 기본, 화면별 위치 설정 및 폴더블 전환 상태 보존. 저장 및 클린 HTML 재열기 영향 확인.
5. 기존 프롬프트/UC/좌표, 엔진/레지스트리, API, 저장 스키마, AndroidBridge, 갤러리 및 원본 이미지 보존. 기존 홈·브랜드 유지. 신규 innerHTML/외부 CDN 금지. APK/Android 변경 금지.
6. 공식 검사: scan_secrets.py, check_index.py docs/index.html, git diff --check. 후보 화면 476×660 / 839×660 / 840×660 / 933×612, 실제 선택·Undo, 이동/복원, 스크롤/터치/키보드/Back, 생성 모의 API, 출력 대조, 저장/백업/HTML 2세대 및 영향 경로 검사. 실제 실행·모의·실기기 구분.
7. 제품 후보와 QA 커밋 분리. 후보/기준 SHA-256 및 blob 기록. 독립 검수·사용자 배포 승인 전 main 반영 금지.
